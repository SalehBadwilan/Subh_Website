# قواعد العمل — تطبيق «صبح» الموبايل (Expo SDK 57)

راجع وثائق Expo الإصدار 57 قبل كتابة أي كود: https://docs.expo.dev/versions/v57.0.0/

## قواعد إلزامية

1. **الهوية البصرية من `src/lib/theme.ts` فقط** — Primary Teal `#0F766E`،
   خط Cairo، نصف قطر أساسي 14. لا ألوان أو خطوط مكتوبة يدويًا في الشاشات.
2. **استخدم `AppText` وليس `Text`** — يضبط الخط والمحاذاة RTL تلقائيًا.
   للأرقام والهواتف مرّر `ltr`.
3. **RTL صريح:** الصفوف ذات الترتيب المهم = `flexDirection: "row-reverse"`
   (العنصر الأول يظهر يمينًا). القوائم الأفقية = `FlatList inverted`.
   لا تستخدم `I18nManager.forceRTL` (لا يثبت في Expo Go).
4. **البيانات والأنواع من `@/shared` فقط** — المجلد مرآة لويب صبح وسينقل
   إلى `packages/shared` لاحقًا؛ لا تستورد من ملفاته الداخلية مباشرة.
5. **نداءات البيانات عبر `shared/api.ts`** — لا `fetch` داخل الشاشات؛
   كل دالة موثقة بالـ endpoint الحقيقي المقابل (تُربط في اليوم 6).
6. **التوكن في SecureStore** عبر `lib/storage.ts` — ممنوع وضعه في
   AsyncStorage أو الحالة العامة.
7. **كل قائمة تحتاج حالات Loading / Empty / Error** — استخدم `EmptyState`.
8. **النصوص للمستخدم عربية** ومطابقة لنصوص الويب حيثما وُجد المقابل.
